Cloud Data Platform · Fitness Marketing & Retention

AWS S3 + Athena · dimensional modeling

Acting as data engineer for Peak Fitness (a boutique brand, 32 locations / 17 cities) migrating off a third-party booking system: designed and built an end-to-end AWS pipeline turning raw operational data — signups, transactions, app engagement — into clean, analysis-ready datasets and business insights.

  • Least-privilege IAM + AWS Budgets cost monitoring; deployed live on AWS.

PROJECT_03

Jaffle Shop Analytics Pipeline

dbt + Snowflake ELT · star schema

End-to-end ELT pipeline turning messy raw transactions into clean, tested, analytics-ready tables to answer one question: which products actually drive profit? Built a star schema — an order-item fact carrying profit, surrounded by customer / product / store dimensions.

  • Key insight: modeling volume correctly overturned an intuitive-but-wrong call — low-margin beverages sell 3–4× more often and generate ~2× the total profit of premium food.
  • Data quality: 21 automated tests across 3 layers — generic (uniqueness / non-null / referential integrity), custom business rules (profit never negative, totals reconcile), and a unit test on the profit-calc logic.
  • Performance: refactored the largest fact table to incremental materialization (with a 3-day late-arrival buffer).
  • Cost + ops: view materialization + auto-suspending XSMALL warehouse; daily cron run-and-test with timestamped logs; flagged (not deleted) 0.78% zero-value orders for auditability.

PROJECT_03

Jaffle Shop Analytics Pipeline

dbt + Snowflake ELT · star schemadbt + Snowflake ELT · 星型模型

End-to-end ELT pipeline turning messy raw transactions into clean, tested, analytics-ready tables to answer one question: which products actually drive profit? Built a star schema — an order-item fact carrying profit, surrounded by customer / product / store dimensions.端到端 ELT 管线,把杂乱的原始交易数据整理成干净、有测试覆盖、可直接分析的表,只为回答一个问题:到底哪些产品真正带来利润?搭建星型模型 —— 以订单明细为事实表承载利润,外围是客户 / 产品 / 门店维度。

  • Key insight: modeling volume correctly overturned an intuitive-but-wrong call — low-margin beverages sell 3–4× more often and generate ~2× the total profit of premium food.关键洞察:把销量建模正确后推翻了一个看似直觉但错误的结论 —— 低毛利饮品的销售频次高出 3–4 倍,总利润约为高价食品的 2 倍。
  • Data quality: 21 automated tests across 3 layers — generic (uniqueness / non-null / referential integrity), custom business rules (profit never negative, totals reconcile), and a unit test on the profit-calc logic.数据质量:3 个层次共 21 项自动化测试 —— 通用测试(唯一性 / 非空 / 参照完整性)、自定义业务规则(利润不得为负、总额可对平),以及针对利润计算逻辑的单元测试。
  • Performance: refactored the largest fact table to incremental materialization (with a 3-day late-arrival buffer).性能:将最大的事实表重构为增量物化(含 3 天迟到数据缓冲)。
  • Cost + ops: view materialization + auto-suspending XSMALL warehouse; daily cron run-and-test with timestamped logs; flagged (not deleted) 0.78% zero-value orders for auditability.成本与运维:视图物化 + 自动挂起的 XSMALL 仓库;每日 cron 跑批并测试,输出带时间戳日志;对 0.78% 的零金额订单做标记而非删除,保证可审计。
